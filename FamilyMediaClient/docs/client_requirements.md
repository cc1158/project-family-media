# FamilyMedia Apple 客户端需求说明与技术架构文档

> 历史说明：本文记录最初 MVP 需求，不代表 `1.0.0-rc.1` 当前能力。当前架构和行为以 `architecture.md`、根目录 README 与发布清单为准。

## 1. 项目名称

`FamilyMedia`

## 2. 项目背景

本项目用于家庭局域网内的视频和照片浏览播放。

家庭中的儿童视频和照片存储在 NAS 上，NAS 上会运行一个轻量级媒体服务端 `family-media-server`。Apple TV 客户端通过 HTTP 接口访问服务端，获取视频和照片列表，并播放或展示对应媒体内容。

当前 MVP 阶段优先开发 Apple TV 端，即 tvOS 客户端。后续可能扩展 iPhone 端，即 iOS 客户端。

因此客户端项目需要从一开始保持良好的结构：

- 当前只实现 tvOS App
- 共享模型、网络、服务层代码
- 为后续 iOS App Target 预留扩展空间
- 不做复杂业务
- 不直接访问 NAS SMB / NFS
- 只通过 HTTP API 与服务端交互

---

## 3. 客户端目标

### 3.1 MVP 目标

MVP 阶段实现以下能力：

- Apple TV App 可以启动
- 首页提供“视频”和“照片”两个入口
- 可以请求服务端 `/api/videos`
- 可以请求服务端 `/api/photos`
- 可以展示视频网格列表
- 可以点击视频并使用系统播放器播放
- 可以展示照片网格列表
- 可以点击照片并全屏查看
- 支持 Apple TV 遥控器焦点操作
- 网络异常时 App 不崩溃
- 空数据时有明确提示
- HTTP 局域网访问可用

### 3.2 非目标

MVP 阶段暂不实现：

- iOS 手机端
- 登录
- 权限管理
- 收藏
- 搜索
- 播放历史
- 断点续播
- 视频转码
- 字幕
- 多音轨
- 照片幻灯片
- 照片左右切换
- 本地缓存
- 离线下载
- 外网访问
- App Store 发布
- 用户设置页面
- WebDAV / SMB / NFS 直接访问
