# Roadmap

## 1.0.0-rc.1：基线收敛

- 固化家庭媒体目录、分页、排序和年月时间线。
- 固化扫描、缩略图、自愈、HEIC/方向和生成数据清理。
- 固化外置 Go 程序与 Docker 内置回退部署。
- 完成 NAS、iPhone/iPad 和 Apple TV 真机验收。

## 1.1：播放连续性

- 设计家庭媒体与 Jellyfin 统一的断点续播语义。
- 保持家庭服务端轻量，不代理 Jellyfin 转码。

## 后续候选

- Live Photo 配对与展示。
- 更丰富但可脱敏的媒体元数据。
- 大媒体库测量驱动的缓存和查询优化。

搜索、收藏、人物识别、多用户权限和公网访问均不属于当前承诺范围。
